# 🌐 AddressFlow — Cadastro Brasileiro Inteligente

O **AddressFlow** é uma aplicação web moderna desenvolvida para otimizar fluxos de cadastro residencial através da automação inteligente de formulários.

Ao capturar o CEP inserido pelo usuário, a aplicação realiza requisições assíncronas em tempo real à **BrasilAPI**, reduzindo erros manuais de digitação e aprimorando significativamente a experiência do usuário.

A interface adota conceitos modernos de design inspirados em *Glassmorphism*, integrados a uma identidade visual baseada na paleta de cores brasileira, com suporte nativo a temas escuro e claro.

---

## 🚀 Principais Recursos

- ⚡ **Automação via BrasilAPI (v2)**  
  Consulta instantânea de dados de endereço através de requisições assíncronas.

- 🌓 **Design Dual-Theme**  
  Alternância fluida entre os modos Dark e Light através da manipulação dinâmica de classes no DOM.

- 🗂️ **CRUD Completo**  
  Criação, leitura, atualização e exclusão de registros diretamente pela interface.

- 💾 **Persistência Local**  
  Armazenamento de dados utilizando a API `LocalStorage`.

- 📱 **Layout Responsivo**  
  Interface adaptável para desktops, tablets e smartphones utilizando Flexbox e CSS Grid.

---

## 🛠️ Stack Tecnológica

| Camada | Tecnologia |
|---|---|
| Estrutura | HTML5 Semântico |
| Estilização | CSS3 Avançado |
| Responsividade | Flexbox + CSS Grid |
| Lógica da Aplicação | JavaScript ES6+ |
| Comunicação HTTP | Fetch API |
| Persistência | LocalStorage |
| API Externa | BrasilAPI (`/cep/v2/`) |
